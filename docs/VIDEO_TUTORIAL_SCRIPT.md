# FastMovieMaker 비디오 튜토리얼 대본 및 스토리보드

이 문서는 FastMovieMaker의 신규 사용자를 위한 3~5분 분량의 **"Quick Start & Core Features" 비디오 튜토리얼 제작 가이드**입니다. 화면 녹화 시 이 스토리보드와 대본(나레이션)을 따라 진행하면 됩니다.

---

## 🎬 튜토리얼 개요
*   **목표:** 설치 후 처음 프로그램을 실행한 사용자가 5분 안에 "미디어 로드 → AI 자막 생성 → 기초 편집 → 내보내기"의 전체 워크플로우를 경험하도록 안내.
*   **예상 소요 시간:** 3~4분
*   **타겟 오디언스:** 숏폼 크리에이터, 초보 동영상 편집자, AI 자동화 도구에 관심 있는 유저.
*   **준비물:** 약 1~2분 길이의 사람 목소리가 포함된 샘플 MP4 영상, FastMovieMaker 최신 버전.

---

## 📝 스토리보드 및 대본 (Script)

### 0:00 - 0:30 | 1. 인트로 및 프로젝트 생성
*   **[화면 연출]**
    1.  FastMovieMaker 웰컴 다이얼로그 화면 표시.
    2.  "New Project" 버튼 클릭.
    3.  프로젝트 이름(e.g., "My First Shorts") 입력 후 "Create" 클릭.
    4.  텅 빈 메인 편집기 화면(다크 테마)이 나타남.
*   **[나레이션 (TTS 또는 육성)]**
    > "안녕하세요! 빠르고 직관적인 AI 비디오 편집기, FastMovieMaker 튜토리얼에 오신 것을 환영합니다. 오늘은 프로젝트 생성부터 AI 자동 자막, 그리고 최종 영상 내보내기까지 핵심 워크플로우를 빠르게 살펴보겠습니다. 먼저 새 프로젝트를 만들고 메인 화면으로 진입해 보겠습니다."

### 0:30 - 1:00 | 2. 미디어 가져오기 및 타임라인 배치
*   **[화면 연출]**
    1.  좌측 상단 `Media` 패널에서 "Import Media" 버튼 클릭.
    2.  준비된 샘플 MP4 영상 선택하여 라이브러리에 추가.
    3.  가져온 영상을 마우스로 드래그하여 하단 타임라인의 `Track 1`에 드롭.
    4.  스페이스바를 눌러 짧게 재생(Play) 및 일시정지.
*   **[나레이션]**
    > "편집할 영상을 불러오는 방법은 아주 간단합니다. 좌측 미디어 패널에서 영상을 임포트한 뒤, 하단의 타임라인으로 드래그 앤 드롭하세요. 스페이스바를 눌러 즉시 재생하며 내용을 확인할 수 있습니다."

### 1:00 - 2:00 | 3. AI 자동 자막 생성 (하이라이트)
*   **[화면 연출]**
    1.  메인 메뉴에서 `Subtitles` → `Generate (Whisper)` 클릭.
    2.  나타난 `Whisper AI Transcription` 다이얼로그에서 Language를 "Korean(또는 Auto)", Model을 "Base"로 선택 후 "Start" 클릭.
    3.  (중요) 실시간으로 자막이 추출되며 다이얼로그 프리뷰 창에 텍스트가 나타나는 모습 강조.
    4.  완료 후, 타임라인 상단 자막 트랙에 클립들이 생성된 것 확인.
    5.  비디오 플레이어에 자막이 오버레이되어 재생되는 모습 시연.
*   **[나레이션]**
    > "FastMovieMaker의 가장 강력한 기능인 AI 자동 자막 생성입니다. 상단 메뉴에서 Whisper 자막 생성을 실행합니다. 언어와 모델을 선택하고 시작을 누르면, 로컬 PC에서 즉각적으로 음성을 인식해 자막 클립을 자동 생성합니다. 이제 플레이어 화면에서 영상과 완벽하게 싱크가 맞는 자막을 확인할 수 있습니다."

### 2:00 - 2:40 | 4. 자막 스타일링 및 번역 (선택)
*   **[화면 연출]**
    1.  우측 `Subtitles` 패널에서 아무 자막이나 클릭 후 텍스트 수정(오타 수정 시연).
    2.  좌측 `Templates` 패널로 이동하여 "YouTube Shorts" 스타일 템플릿 더블 클릭.
    3.  비디오 플레이어의 자막 폰트, 색상, 애니메이션이 일괄 변경되는 모습 강조.
    4.  (선택 사항) `Translate` 버튼을 눌러 한국어 자막을 영어로 원클릭 번역하는 모습 짧게 시연.
*   **[나레이션]**
    > "우측 패널에서 오타를 쉽게 수정할 수 있습니다. 또한 좌측의 템플릿 패널에서 원하는 스타일을 선택하면, 모든 자막의 폰트, 색상, 애니메이션이 일괄 적용되어 순식간에 프로페셔널한 룩을 완성할 수 있습니다. 필요한 경우 원클릭 다국어 번역 기능도 활용해 보세요."

### 2:40 - 3:15 | 5. 영상 내보내기 (Export) 및 마무리
*   **[화면 연출]**
    1.  우측 하단 (또는 File 메뉴) `Export Video` 버튼 클릭.
    2.  `Export Video` 다이얼로그에서 Format(MP4), Resolution(1080p), Encoder(하드웨어 가속 체크) 확인.
    3.  "Export" 버튼 클릭 후 진행률(Progress Bar)이 차오르는 모습.
    4.  완료 알림창이 뜨고, 출력된 최종 폴더가 열리는 모습.
*   **[나레이션]**
    > "편집이 끝났다면 내보내기 버튼을 누릅니다. 하드웨어 GPU 가속을 지원하여 매우 빠른 속도로 렌더링이 진행됩니다. 이것으로 FastMovieMaker를 활용한 첫 번째 영상 편집이 끝났습니다! 더 많은 고급 기능은 공식 문서를 참조해 주세요. 감사합니다."

## 💡 촬영 팁 및 권장 설정
*   **해상도:** 화면 녹화는 1920x1080 (1080p) 또는 2560x1440 (1440p) 해상도로 진행하세요.
*   **마우스 효과:** 클릭 시 마우스 커서에 원형 하이라이트 효과가 나타나도록 녹화 소프트웨어를 설정하면 시청자가 따라하기 쉽습니다.
*   **단축키 노출:** 스페이스바 재생, 자막 생성(단축키 매핑 시) 등 주요 단축키를 사용할 때 화면 하단에 텍스트 키스트로크가 표시되도록 구성하면 더욱 유용합니다.
*   **배경 음악:** 잔잔하고 방해되지 않는 Lo-Fi 또는 Acoustic BGM을 볼륨 10~15% 수준으로 깔아주는 것을 권장합니다.
